## Interactive widget

Because this file is `.mdx`, React components can be dropped inline. The
`client:visible` directive is what makes it interactive: Astro ships the
component's JavaScript only when the reader scrolls it into view, so the rest
of the page stays static HTML.

<FigureSlider
  client:visible
  name="Layer"
  frames={[
    { src: "/projects/demo/layer-01.svg", label: "1",  caption: "Early layers attend locally." },
    { src: "/projects/demo/layer-16.svg", label: "16", caption: "Mid layers spread across modalities." },
    { src: "/projects/demo/layer-32.svg", label: "32", caption: "Late layers concentrate on the answer span." }
  ]}
/>

The component lives in [src/components/FigureSlider.tsx](https://github.com/peterwisu)
— copy it as the starting point for any other widget.
